# MoneyOS v0.1
Upload all files at repository root. In GitHub Settings > Pages choose Deploy from a branch, main, / (root). Open the published HTTPS URL in iPhone Safari, Share > Add to Home Screen. Open once online before using offline. No external dependencies. Data is stored in localStorage; export backups regularly. Encrypted backup uses AES-GCM and PBKDF2; live storage is not encrypted. No automatic bank sync, notifications, recurring transactions or live investment prices. Asset values and debt balances are manual. Bills do not automatically post transactions. Amounts are stored in integer paise. JavaScript syntax checked; physical iOS and browser interaction tests still required. When updating shell files increment CACHE in sw.js. Never upload personal backup files to GitHub.

## v0.2 Debt Intelligence
Open Debt to add or edit existing liabilities (legacy records need complete terms). Enter expected monthly income, expenses excluding debt, reserve contribution and integer horizon. FinEngine compares five deterministic strategies using monthly nominal reducing-balance interest and optional percentage prepayment fees. It does not implement actual credit-card daily interest, flat-rate loans, or neural networks yet. Debt balance edits are manual snapshots and do not create transactions. Do not duplicate credit card balances in Accounts and Debt. Keep the same GitHub Pages origin and path to retain existing localStorage; export a backup before upgrading. Live records remain unencrypted. On iOS, open in Safari and Add to Home Screen; offline availability requires successful initial caching. Run `node engine.test.js` for engine checks. No physical iPhone test performed.

## Ultimate consolidated build
Upload runtime files to the root of a GitHub repository, enable Settings > Pages > Deploy from branch > main / root. Open the HTTPS Pages URL in Safari, Share > Add to Home Screen. Open once online before offline use. Existing data migrates implicitly only when hosted at the same origin (localStorage key unchanged). Export a backup before updating. No personal data should be committed to GitHub.

Intelligence tab: enter conservative monthly income, all non-debt expenses, reserve contribution, horizon and search effort. Worker searches sampled fixed-priority permutations plus five baseline strategies; no global optimum or beam search claim. Stress analysis uses 300 hypothetical persistent budget shocks, not real-world probabilities. Refinance assumes equal tenure and fixed rates. Forecast uses a tiny locally trained neuron only if at least eight months and a single holdout beats a mean baseline; otherwise trailing mean. Not a validated financial predictor.

Shortcut: in Apple Shortcuts add Ask for Input (Number), then Ask for Input (Text), then URL with your Pages URL and amount/note query parameters (URL encode note), then Open URLs. Prefer no sensitive note in URL; URLs may enter browser history. Review transaction and save manually. No automatic SMS access or background reminders.

Security: localStorage remains plaintext; encrypted backup uses AES-GCM/PBKDF2. Device passcode and regular encrypted exports recommended. No IndexedDB migration or live database encryption in this release. No third-party runtime dependencies. Monthly reducing balance only; actual lender rules may differ. No real iPhone/browser integration testing performed. Run node engine.test.js and node intelligence.test.js.
